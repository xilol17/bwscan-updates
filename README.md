## 更新内容 / What's new in 2.3

新增「证件」模式：拍身份证 / IC / 驾照 / 银行卡的正面和反面，自动裁正成标准证件大小，正反面排在同一张 A4 上导出 PDF 或图片。
· 首页点「证件」，按提示先拍正面、再拍反面（也可从相册选两张照片）
· 可选实际尺寸（85.6 × 54 mm）或放大 1.5 / 2 倍，打印选「实际大小」即与原件一样大
· 可加斜向水印，如「仅供 XX 银行开户使用」
· 可交换正反面、点按单面重新调整

New ID card mode: photograph the front and back of an ID / IC / driving licence / bank card. Both sides are cropped to the standard card size and placed on one A4 page, exported as PDF or image.
· Tap "ID card" on the home screen, shoot the front, then the back (or pick two photos)
· Actual size (85.6 × 54 mm) or enlarged 1.5× / 2×; print at "Actual size" for a 1:1 copy
· Optional diagonal watermark, e.g. "For XX bank account opening only"
· Swap sides, or tap a side to adjust it
